# Digi

A party camera for iPhone: 2005 digicam flash, the orange date stamp, booth strips, AI re-light and Live digi videos.

**Start here:** read [`STATUS.md`](STATUS.md) for decisions, the AI recipe, what's built and the next steps. Then read [`AGENTS.md`](AGENTS.md) for the Expo SDK 58 rules.

- App: Expo SDK 58, Expo Router and TypeScript (`src/app/`)
- Research and design: [`docs/research/`](docs/research/)
- AI model test, recipe and prompts: [`docs/model-test/`](docs/model-test/)

```bash
npm install
npx expo start        # dev server
npx tsc --noEmit      # typecheck
npx expo lint         # lint
```
